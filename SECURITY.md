# Security Policy

LEGECY is an experimental open-source project.

## Reporting a vulnerability

If you discover a security vulnerability, please contact the maintainer privately
before publicly disclosing the issue.

Do not publish:

- private keys
- seed phrases
- API keys
- authentication tokens
- trading credentials
- personally sensitive information

## Trading security

LEGECY should never require a private key for public wallet monitoring.

Live trading credentials must remain outside the public repository.
