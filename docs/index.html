LEGECY Documentation

Understand the intelligence behind the wallet.

LEGECY turns raw Solana transaction activity into a structured wallet intelligence profile — behavior, trading activity, protocol usage, reputation, Smart Money signals and confidence in the available data.

LEGECY is an experimental intelligence system. Scores are signals derived from observed on-chain data, not financial advice or guarantees of future performance.

Architecture

The current product is centered on a read-only analysis pipeline. Each layer transforms the previous layer into a more useful representation.

Solana Wallet → Transaction History ↓ Wallet-specific balance changes + programs + logs ↓ Transaction Decoder ↓ Protocol Registry + Swap Detection ↓ Trade Extraction + SOL/WSOL normalization ↓ Trade Engine → FIFO realized P/L ↓ Wallet Statistics + Behavior Intelligence ↓ Reputation + Smart Money ↓ Data Confidence ↓ LEGECY Wallet Profile

Wallet Intelligence

Enter a Solana wallet address to analyze its observed transaction history. LEGECY decodes transactions instead of assuming that a token appearing in a wallet represents a purchase.

Trading behavior

Trading style, frequency, risk level, token diversity and protocol diversity.

Execution

Successful swaps, failed swaps, attempts and failure rate.

Performance

Closed trades, wins, losses, win rate and FIFO realized P/L.

Protocol activity

Detected protocol usage and relative activity share.

Smart Money

The Smart Money Engine combines wallet activity, token diversity, protocol diversity, swap reliability, reputation and data coverage into a single signal.

Ratings: STRONGGOODMODERATEWEAKLOW

Smart Money confidence is tied to how much usable transaction data was actually analyzed. Missing data should reduce confidence rather than create artificial certainty.

Wallet Comparison

Compare two analyzed wallets across Smart Money, reputation, trading activity, token diversity, swap success, failure rate and protocol diversity. The result includes per-metric winners, a composite comparative signal and confidence limited by the less-confident wallet.

Smart Wallet Discovery & Ranking

Discovery finds wallets that repeatedly interact with a seed wallet through shared transaction signers and then analyzes candidates.

Ranking applies Smart Money, reputation and data confidence to rank candidate wallets. A minimum confidence filter prevents thin data from being presented as strong evidence.

Watchlist

The Watchlist stores wallets you want to revisit. The production implementation uses SQLite at data/watchlist.db, backed by a Railway persistent Volume mounted at /app/data.

Supported actions: add a wallet with a label, list saved wallets, check whether a wallet is watched, and remove a wallet. Duplicate wallet entries are prevented.

Data Confidence

LEGECY reports how much of the requested transaction history was actually analyzed. Confidence considers requested, analyzed and unavailable transactions. This distinction matters because a score based on ten analyzed transactions is not equivalent to a score based on ten requested transactions where several could not be retrieved.

Security & Reliability

  • Read-only wallet analysis — no private keys are requested.
  • Wallet address validation before analysis.
  • Rate limiting and bounded concurrency.
  • Timeout handling for wallet analysis.
  • Response caching for repeated analysis requests.
  • Security response headers in production.
  • SQLite WAL mode and persistent storage for watchlist data.
  • Automated regression tests through CI.

Limitations

  • Transaction history availability depends on the upstream Solana RPC and the requested analysis window.
  • Token presence alone does not prove a purchase.
  • Realized P/L is based on decoded and matched trade activity available to the engine.
  • Smart Money and reputation are analytical signals, not predictions.
  • Discovery is based on observed transaction relationships and can miss relevant wallets.
